## 📌 What I Built!


**Event Aggregator Web App** is a modern full-stack Web2 platform where users can view, filter, and submit upcoming **college tech events** like:

- 🛠️ Hackathons  
- 🧠 Tech Talks  
- 📚 Workshops  

The app supports both **manual event submissions** and **mock-scraped event data**, helping students and developers stay updated with real opportunities.

---

## 🌟 Key Features

| Feature                    | Description                                                                 |
|----------------------------|-----------------------------------------------------------------------------|
| 📅 Event Dashboard         | List of upcoming tech events in a card layout                               |
| 📤 Submit New Events       | Event name, date, location, description, and link                           |
| 🔍 Search & Filters        | Filter by event type, date, location, or college                            |
| 🔐 Auth System             | Login/Register using JWT + bcrypt                                           |
| 🎨 Animated UI             | Smooth transitions and effects (Framer Motion)                              |
| 📱 Fully Responsive        | Tailwind CSS + Mobile-first responsive design                               |

---

## 🧰 Tech Stack

**Frontend:**
- React.js
- Tailwind CSS
- React Router
- Framer Motion

**Backend:**
- Node.js + Express
- MongoDB + Mongoose
- JWT Auth + bcrypt

## 🚀 Getting Started Locally

```bash
# Clone the repo
git clone https://github.com/shriyashsoni/event-aggregator-app.git
cd event-aggregator-app

# Frontend setup
cd client
npm install
npm run dev

# Backend setup
cd ../server
npm install
node index.js
```

Create `.env` inside `/server/`:

```env
MONGO_URI=your_mongo_db_connection
JWT_SECRET=your_jwt_secret
PORT=5000
```
